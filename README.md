Quiz Game in C

This is a simple console-based quiz game developed using the C programming language. The project allows users to answer multiple-choice questions and calculates the final score based on correct answers. Questions are displayed randomly so the quiz experience feels different each time the program runs.

The project is designed for beginners who want to practice important C programming concepts such as structures, arrays, functions, loops, conditional statements, random number generation, and user input handling. All quiz questions, options, and correct answers are stored using a structure (struct) for better organization and easier management of data.

When the program starts, the user is welcomed to the quiz game. The program then randomly selects a question from the available list and displays four answer options. The user must enter a number between 1 and 4 to choose an answer. If the selected answer is correct, the score increases; otherwise, the correct answer is displayed. After all questions are completed, the final score is shown to the user.

This project uses standard C libraries such as stdio.h for input and output operations, stdlib.h for random number functions, string.h for copying question data, and time.h for generating different random sequences each time the program runs.
